# Traductions

L'interface est fournie en anglais (`en`) et en français (`fr`). Par défaut, elle
suit les préférences du navigateur (`Browser language`), et l'utilisateur peut
choisir explicitement la langue dans **Manage › Settings › Flow UI** (*Interface ›
Language*) ou depuis le bouton **⚙** d'un écran. Ce choix est mémorisé dans ce
navigateur (`localStorage`), s'applique immédiatement et n'entre pas dans les
réglages serveur. Tout texte visible passe par `t()` :

```js
import { t } from "../i18n/index.js";

t("flows.title");                            // "Flows Monitoring"
t("flows.updated", { time: "10:42" });       // "Updated 10:42"
t("flows.group.channels", { count: 3 });     // "3 channels"
```

- Les catalogues sont dans `src/i18n/locales/`. `en.js` est la référence : chaque
  clé y existe (un test le vérifie pour toutes les clés écrites en clair dans le
  code).
- `{nom}` est remplacé par le paramètre du même nom ; un nombre est mis en forme
  selon la langue (`1,200` ou `1 200`).
- Une entrée à plusieurs formes (`{ one: "...", other: "..." }`) est choisie avec
  le paramètre `count`, selon les règles de pluriel de la langue (`Intl.PluralRules`).
- La langue suit la préférence locale du navigateur si elle est fixée (`en`, `fr`),
  sinon la première langue du navigateur qui a un catalogue (`auto`), sinon l'anglais.
  Une clé absente d'une traduction retombe sur l'anglais.

Web Admin n'a pas de mécanisme de traduction (WA-07) : quand il en aura un, Flow UI
suivra la langue de l'utilisateur.

## Ajouter une langue

1. Copier `src/i18n/locales/en.js` (par exemple vers `de.js`, code BCP 47 de la
   langue) et traduire les valeurs, sans changer les clés. Un test unitaire
   vérifie que chaque catalogue possède les mêmes clés et paramètres que `en.js`.
2. Déclarer le catalogue dans `src/i18n/index.js` :

   ```js
   import de from "./locales/de.js";
   const CATALOGS = { en, fr, de };
   ```

3. Ajouter l'entrée `settings.language.de` (libellé natif, par exemple `"Deutsch"`)
   dans `en.js`, `fr.js` et le nouveau catalogue pour qu'elle apparaisse dans le
   sélecteur de langue.
4. Les formes de pluriel suivent la langue : le français utilise `one` et `other`,
   d'autres langues `few`, `many`…
5. `npm test`, `npm run check`, `npm run build`, puis vérifier les deux écrans dans
   la démo : les textes plus longs doivent rester lisibles (titres tronqués avec
   info-bulle).

Les noms de statuts (`Received`, `Errored`…) reprennent ceux de Web Admin : les
garder cohérents avec sa traduction, le jour où elle existera.
